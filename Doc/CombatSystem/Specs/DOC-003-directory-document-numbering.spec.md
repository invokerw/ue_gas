## 3. 行为与契约

- 命名为 `<目录号>-<两位序号>-<主题>.md`，主题可使用中英文，序号从 01 开始。例如架构目录使用 `10-01` 至 `10-11`。
- 项目、架构、内容、工具、历史目录分别使用 `00`、`10`、`20`、`30`、`90`；同目录序号不得重复。
- 标题与链接显示编号随文件名同步；原始章节号、M0–M8、F/G Gate、Task、ADR/Gap、测试计数保持原义。
- 历史文档只修正文件定位与编号，不改写决策和验收结果。
- 校验拒绝目录号不符、缺少两位序号、零序号和重复序号；README 与下划线模板除外，Spec 继续使用任务编号。
